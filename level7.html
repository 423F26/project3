Level 7: Else Statements!

Step 1 of 4

🦁 Remember If Statements?

In Level 5 you learned that an if statement checks whether something is true. If it is true, the computer runs the code inside the curly brackets.

if (hungry) { eat() }

But what if your animal is not hungry? Right now the computer just skips the code and does nothing at all. Wouldn't it be nice to tell your animal what to do instead?

Step 2 of 4

Meet "else"!

else means "otherwise". It gives the computer a second plan for when the condition is false.

if (hungry) { eat() } else { play() }

This means: IF your animal is hungry, it eats. OTHERWISE, it plays.

Step 3 of 4

What Do the Parts Mean?

  • if (hungry) checks the condition, just like before.
  • The first { } holds what to do when the condition is true.
  • else comes right after the first closing bracket }. It can never be used by itself.
  • The second { } holds what to do when the condition is false.

Here's the most important rule: only ONE of the two parts ever runs. Never both, and never neither!

Step 4 of 4

Picking a Path

Think of if / else like a fork in a path. Your animal always walks down exactly one side:

if (raining) { umbrella() // path 1: it IS raining } else { sunglasses() // path 2: it is NOT raining }
