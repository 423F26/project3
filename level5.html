Level 5: If / Then Statements!

🐧 Let's Learn About If / Then Statements!

Computers can make decisions! An if statement checks whether something is true. If it is true, the computer follows the instructions inside the curly brackets.

Here's how it works:

if (hungry) { eat() }

This means: IF the penguin is hungry, THEN it will eat. If the penguin is not hungry, it will skip that instruction.

What Do the Parts Mean?

  • if tells the computer to check a condition.
  • ( ) Parentheses hold the condition being checked.
  • { } Curly brackets hold the action to perform when the condition is true.
  • eat() is the action the computer should perform.

One More Example!

if (raining) { umbrella() }

The penguin only gets an umbrella if it is raining. That's how code can help a computer make decisions!
