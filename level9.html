Level 9: While Loops!

Step 1 of 4

🐨 Doing Things Over and Over

Your animal has 4 leaves to eat. We could write eat() four times... but what if it had 100 leaves? That would be a LOT of typing!

A while loop tells the computer to keep repeating some code as long as something is true.

while (leaves > 0) { eat() }

This means: WHILE there are more than 0 leaves, keep eating!

Step 2 of 4

What Do the Parts Mean?

  • while tells the computer to repeat.
  • ( ) Parentheses hold the condition. The loop keeps going while it is true.
  • leaves is a variable: a name that holds a number that can change.
  • > means "greater than" and < means "less than".
  • { } Curly brackets hold the code to repeat.

Step 3 of 4

Check, Run, Check Again!

Every time around the loop, the computer checks the condition first:

leaves = 2: 2 > 0 is TRUE → eat() leaves = 1: 1 > 0 is TRUE → eat() leaves = 0: 0 > 0 is FALSE → stop!

Each eat() makes leaves go down by 1. When the condition finally becomes false, the loop stops.

Step 4 of 4

⚠️ Watch Out for Forever Loops!

If the condition never becomes false, the loop never stops! Programmers call this an infinite loop.

while (leaves >= 0) { eat() } // leaves can't go below 0, so this is ALWAYS true!

Always make sure the code inside your loop moves things closer to making the condition false.
