ZooCode User Guide

ZooCode is a web game that teaches elementary students the basics of coding. Students solve levels by moving a character around the screen, first with the arrow keys and then with typed text commands.

This guide is for students and for the teachers or parents helping them get started.

Getting Started

  1. Open a web browser such as Chrome, Firefox, Edge, or Safari.
  2. Go to [your Firebase URL]. This opens the home page.
  3. The home page shows the level selector with Levels 1 through 15.
  4. Click Level 1 to start. New players should begin here, since later levels build on earlier ones.

Playing a Level

  1. Each level shows a character on the screen and asks you to move it somewhere.
  2. In the early levels, use the arrow keys on your keyboard to move the character up, down, left, and right.
  3. In later levels, you type text commands instead of pressing arrow keys. [Add an example command here, e.g. what a student types to move right.]
  4. A message with appear to let you know that you've finished the level.
  5. To play another level, go back to the home page and pick it from the level selector.

Troubleshooting

  • The page won't load: Check your internet connection, refresh the page, or try a different browser.
  • The arrow keys don't move the character: Click once inside the game area so it is selected, then try the arrow keys again.
  • A level seems stuck or isn't working: Refresh the page to restart the level, or go back to the home page and select it again.

Current Limitations

ZooCode is still being built, so a few things are not finished yet:

  • All levels are open. You can pick any level from 1 to 15 at any time. Later, levels will unlock one at a time as you finish the one before.
  • Loops and functions are not available yet. Current levels cover arrow-key movement and text commands. Levels teaching loops and functions are planned.
  • The game is designed to be played with a keyboard, so it works best on a computer rather than a phone or tablet.
