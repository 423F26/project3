Level 10: User Input!

Step 1 of 4

💬 Programs That Listen

So far, your programs have done the exact same thing every time they run. But most programs you use listen to you!

A game asks for your name. A search box waits for you to type. Anything the user types or clicks is called user input.

Step 2 of 4

❓ Asking a Question

name = ask("What is your name?")
  • ask( ) shows a question and waits for the user to type an answer.
  • The question goes inside " " quotes.
  • name = saves the answer in a variable called name, so you can use it later.

Step 3 of 4

🗣️ Using the Answer

name = ask("What is your name?") say("Hello " + name)
  • say( ) makes your animal say something.
  • "Hello " has quotes, so it says those exact words.
  • name has no quotes, so it uses whatever the user typed!
  • + joins them together.

If you type Sam, your animal says "Hello Sam"!

Step 4 of 4

🔀 Different Answers, Different Results

Remember if / else from Level 7? You can use it to check what the user typed. == checks if two things are the same:

answer = ask("Are you hungry?") if (answer == "yes") { say("Let's eat!") } else { say("Let's play!") }
