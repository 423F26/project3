# Second Grade Coding Teaching Tool
** This is a level progression based game that was created for second graders to learn the basics of coding. We wanted to make it fun and engaging.

# Inital Set Up
- The main website is written in HTML
- All of the features are written in JavaScript
- In order to get the code, just download the zip file from GitHub
- In order to host the website, we used Firebase
- Firebase was also used for database, so students can login to the website and their rewards would be saved.

# Build and Run
- The easiest way to run the code would be to clone the repo from GitHub and then opening the file from the command line
- In order to launch the actual website, just hit run in whatever code editor you're using
- To make sure the website works, just play around with the levels and make sure the animals get saved to the home screen
