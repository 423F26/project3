Level 1: What is Coding?

Coding is the language that we use to talk to computers and tell them what to do. A computer, by itself, doesn't understand english words phrases like "Hows it going today?" or "Could you please clean my shoes?" Instead, we use coding languages that use very specific commands which a computer can understand better. For example, teling our character here to move up, down, left, or right.

You just moved the character by pressing keys. Programmers usually give a computer instructions by typing commands instead. Next, you'll move the character by typing commands like up(), down(), left(), and right(). Each command moves the character one space in that direction. For example, right() moves the character one space to the right.
