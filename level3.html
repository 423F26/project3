🐧 Let's Learn About Loops!

Lesson 1 of 4

What is a loop?

Sometimes we want to tell the computer to do something repeatedly without writing the same instructions multiple times.

For example, our penguin might want to move forward 5 spaces. Instead of writing "right()" five times, we can use a loop!

How do we write a loop?

We use the word repeat to tell the computer how many times to do something.

repeat(5) { right() }

This tells the penguin to move right 5 times!

What do the symbols mean?

  • ( ) Parentheses: These hold the number of times to repeat something.
  • { } Curly brackets: These hold the instructions we want the computer to repeat.
  • right(): This tells our penguin which action to do!

Why use loops?

Without a loop:

right() right() right() right() right()

With a loop:

repeat(5) { right() }

Instead of writing the same command five times, we can write it once inside a loop!
