Level 8: Functions!

Step 1 of 4

📦 Making Your Own Commands

So far you've used commands that were already made for you, like right() and up().

But what if you need to do the same group of commands again and again, like hopping over a rock? You can make your own command! This is called a function.

Step 2 of 4

Making a Function

function hop() { up() right() right() down() }
  • function tells the computer "I'm making a new command."
  • hop is the name you choose for it, followed by ( ).
  • The { } hold the commands that hop() will do.

Step 3 of 4

📣 Calling a Function

Making a function is like writing down a recipe. It doesn't actually do anything until you use it!

To use it, write its name with ( ). This is called calling the function:

hop() hop()

Each time you call hop(), your animal does all four commands inside it. Two calls = two hops!

Step 4 of 4

Why Use Functions?

  • Less typing: write the commands once, use them as many times as you want.
  • Easy to read: hop() tells you what's happening better than four separate commands.
  • Easy to fix: if there's a bug, you only fix it in one place!
