Level 11: Booleans & Conditions!

Step 1 of 5

🐼 True or False?

A boolean is the simplest kind of value in coding. It can only ever be one of two things: true or false. Like a light switch: on or off!

daytime = true raining = false

You've already used booleans! In if (hungry), hungry is a boolean. It's either true or false.

Step 2 of 5

AND: &&

Sometimes you need to check two things at once. && means AND. It is only true when both sides are true.

if (sunny && warm) { swim() }

Your animal only swims if it is sunny AND warm. Sunny but cold? No swimming!

Step 3 of 5

OR: ||

|| means OR. It is true when at least one side is true. (You type | by holding Shift and pressing the key above Enter.)

if (hungry || bored) { snack() }

Your animal snacks if it is hungry OR bored, or both! It only skips the snack if it is neither.

Step 4 of 5

NOT: !

! means NOT. It flips a boolean to the opposite: true becomes false, and false becomes true.

if (!raining) { goOutside() }

Your animal goes outside if it is NOT raining.
